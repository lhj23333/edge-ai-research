.venv/bin/researcher prepare-models

自动研究同时受每日总额度约束。自动更新沿用关注名单页面中的开关；未开启时不推进后续问题。原文、证据和记忆保存在本机。

{{ icon('terminal') }}本机运行

{{ '后台研究服务运行中' if worker_alive else '后台研究服务未运行' }}

网站与后台研究服务需要同时运行。关闭浏览器不影响已经启动的后台服务。

在项目目录运行：

.venv/bin/researcher run

后台常驻与开机登录后启动：

.venv/bin/researcher install-services
systemctl --user enable --now researcher-web researcher-worker

备份、恢复及模型 API 文档见项目 README。数据和密钥保存在本机 data 目录，密钥文件不加入版本管理。
